## 1. Информация о проекте

## 2. Тип исследования

**Смешанное (Mixed-Methods)** с преобладанием количественного компонента.

- Количественный компонент (RQ2): сравнение Engagement Rate между платформами/форматами, статистические тесты и регрессия. Позволяет проверить гипотезу эмпирически на выборке ~500 видео.
- Качественный компонент (RQ1): контент-анализ нарративных паттернов и визуально-аудиальных триггеров. Объясняет механизм, который сами метрики не показывают.
- Дизайн наблюдательный, поэтому результаты интерпретируются как **ассоциация**, а не причинность.

## 3. Формулировка гипотез (с уточнениями Недели 5)

Фактор «платформа/формат»: TikTok, Instagram Reels (короткие видео) и YouTube long-form (длинные).

- **H0:** медиана log-ER видео о гипергамии на коротких форматах (TikTok, Reels) не отличается от медианы на YouTube long-form: `Med(log-ER_short) = Med(log-ER_long)`.
- **H1:** медиана log-ER на коротких форматах выше, чем на YouTube long-form: `Med(log-ER_short) > Med(log-ER_long)` (односторонняя, α = 0,05).

## 4. Матрица переменных

| Тип | Переменные |
|---|---|
| **Независимые** | Платформа/формат (TikTok, Reels, YouTube long-form); набор хэштегов (#hypergamy, #levelup) |
| **Зависимые** | ER = (likes + comments) / views; log-ER; доли нарративных категорий (NLP/контент-анализ) |
| **Контролируемые** | Тема (гипергамия/отношения); язык публикаций (en); период 01.2026–09.2026; порог просмотров ≥ 1000; версии библиотек (exact pins) и Docker-образ `python:3.11.9-slim`; random seed = 42; источник данных (официальные API) |
| **Ковариаты** (в регрессии) | Число подписчиков автора, длительность видео, возраст публикации на момент сбора |

Примечание: репосты исключены из ER, так как они публично недоступны на YouTube; это обеспечивает сопоставимость платформ.

## 5. Выбранные метрики и Baseline

**Первичная метрика (Primary):** разность медиан log-ER между короткими и длинными форматами (Δ), проверяемая перестановочным тестом (5000 перестановок, односторонний), с размером эффекта Cliff's δ.

**Вторичный анализ:** Kruskal-Wallis по трём платформам + попарные тесты Манна-Уитни с поправкой Холма; OLS-регрессия log-ER с ковариатами.

**Пороговые метрики (Guardrail):**

- доля записей без пропусков в views/likes/comments ≥ 95%;
- доля ошибок API/сбора ≤ 5%;
- отсутствие дубликатов `video_id`;
- согласие аннотаторов (Cohen's κ) ≥ 0,7 для контент-анализа;
- соблюдение rate limits и условий использования платформ; данные анонимизированы.

**Baseline (контрольная группа):** YouTube long-form как точка сравнения для коротких форматов. Для честности сравнения дополнительно используются:

1. перестановочный тест как нулевая модель (распределение разности при отсутствии эффекта);
2. контрольная выборка видео на нейтральную тему, чтобы отделить эффект платформы от эффекта темы.

## Ограничения

Наблюдательные данные (нет случайного назначения), различие аудиторий платформ, различия в определении просмотра между платформами, недоступность части метрик. Sample-данные в репозитории синтетические и служат только для проверки пайплайна.
